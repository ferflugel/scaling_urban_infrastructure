## Data

The data files are structured as follows:

- **Raw Files**: Original data as initially downloaded.
- **Clean Files**: Generated by `clean_data.py`, these files contain processed data from SNIS and IBNET, which are used to produce most figures.
- **Pickle Files**: Store results from computationally intensive processes (optimizations used for Figures 3B and S7). The file `../data/pickle/zipf_data` is excluded due to size constraints but is available upon request.
